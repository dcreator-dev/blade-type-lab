# ⚔️ Blade Type Lab

**Interactive forge of "blades" for Cyrillic headlines — skew, chamfer cuts, and spikes with SVG/PNG/CSS export.**

Интерактивная кузница «лезвий» для кириллических заголовков — наклон, срезы и острия на терминалях с экспортом в SVG/PNG/CSS.

---

## 🇺🇸 About
Blade Type Lab is a typography playground I built to recreate the aggressive "blade" style of display fonts using any Cyrillic font. Instead of relying on paid fonts, you get the same effect with Tektur or Molot + skew + Boolean Subtract — right in the browser.

## 🇷🇺 О проекте
Blade Type Lab — типографическая лаборатория, которую я создал, чтобы воссоздать агрессивный «лезвийный» стиль дисплейных шрифтов на любом кириллическом шрифте. Вместо платных шрифтов — тот же эффект через Tektur/Molot + skew + Boolean Subtract, прямо в браузере.

---

## ✨ Features / Возможности

- 🔤 **Cyrillic-first fonts** — Tektur, Molot, Russo One, Exo 2, Oswald, Saira Condensed
- ✂️ **4 blade modes** — chamfer cuts, point spikes, sharp tips, or clean font
- 📐 **Live skew** — от -26° до +8° в реальном времени
- 🎨 **6 gradient palettes** — silver, brand, steel, acid, magenta, solid
- 📊 **Before/After comparison** — слайдер для сравнения с лезвиями и без
- 📤 **Export** — PNG (шрифт запечён), SVG (вектор), CSS-сниппет
- 📋 **Figma guide** — готовая инструкция для сборки в Figma
